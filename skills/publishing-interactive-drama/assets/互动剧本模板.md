# 作品：全球冰封

## 节点：N001｜暴雪预警
- 类型：起点
- 选择标题：末日将至，你准备怎么做？
- 分支：
  - 立刻囤积物资 → N002
  - 先回家确认情况 → N003

### 剧本
```text
下午三点，手机同时响起十几条极端天气预警。

窗外的气温正在以不可思议的速度下降。超市方向已经排起长队，而家里的电话始终无人接听。
```

## 节点：N002｜抢购物资
- 类型：普通
- 后续节点：N004

### 剧本
```text
你冲进超市，货架前挤满了人。经过一番争抢，你拿到了最后一箱饮用水和几袋压缩食品。
```

## 节点：N003｜赶回住所
- 类型：普通
- 后续节点：N004

### 剧本
```text
你赶回住所，发现家人已经安全撤离，只在桌上留下了一张字条。风雪封住了街道，你决定先加固房间。
```

## 节点：N004｜深夜求救
- 类型：普通
- 选择标题：要不要开门救她？
- 分支：
  - 打开房门 → E001
  - 保持沉默 → E002

### 剧本
```text
午夜，门外传来急促的敲门声。一个陌生女孩隔着门说，她知道救援队明天会经过的路线。
```

## 节点：E001｜并肩求生
- 类型：结局
- 后续节点：无

### 剧本
```text
你打开门。第二天清晨，她带你找到救援队留下的信号，两个人一起踏上了撤离路线。
```

## 节点：E002｜漫长等待
- 类型：结局
- 后续节点：无

### 剧本
```text
你没有回应。门外的声音渐渐消失，暴雪仍在继续，而你只能独自等待下一次机会。
```
